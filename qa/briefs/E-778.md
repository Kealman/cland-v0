- `curl | sh` exit 0 alone is not a pass: read the script's output for the bundle and the version.
- A cached CDN response can lag GitHub Pages by minutes: note the `age` or `date` header with the C4–C6 fetches.
- Homebrew on Linux is not macOS: label C1 as such, and don't claim a macOS run.
- Never run brew or install.sh on the human's machine. Droplet only.
