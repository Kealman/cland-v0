# QA brief: E-1531 — Definition of done (The Host interface and the local host)

This brief is the Definition-of-done demo of epic E-1531 (qa skill, "Epic demos on a named dev commit"). QA runs it in the human's place at a named `dev` commit and records one epic verdict that names, by id, the criteria it verified (C1–C6). Everything the run needs is in this file or in the files it names: whoever runs it cannot ask. Commands are for bash (zsh reads `$B:h` or `$S:q` as modifiers).

**Where it runs.** Locally, on macOS, from a clean detached worktree at the requested SHA, with `QA_DEMO_EPIC` unset. There is no `cland demo start`, so no lease, deadline, lifetime or cost. The DoD names no droplet ("No real provider, droplet or key is involved"). Every session of this epic runs on the Mac, and the scratch rows need macOS: BSD `sed -i ''`, `darwin` birth identities and the macOS-only Seatbelt Git test. `cland demo status` reads freshness without a lease. No browser, no GUI and no real harness: the scratch hub runs the fake `claude`, `codex` and `opencode` of `hub/test/fakes/`.

The run has three parts, framed by gates E1531D-00 and E1531D-01 and the freshness check E1531D-20:

- **Part T, named tests at S** (E1531D-02 to E1531D-09). One criterion per row, test files run one at a time from the build. This part holds the contract suite's report for `local` (C1), the boundary and its planted negative control (C2), the spy `local` host that proves "never probed" (C3), the Host realpath tests (C4), the recording-Host ordering test (C5) and the placement tests (C6).
- **Part C, the full suite** (E1531D-10). QA re-reads the stage covers at the tested tree: Linux 801d32a7 (A-15573) and macOS 11f9a8be (A-15577), both green at c14994a2. QA checks that they apply to the build under test, or obtains a fresh occasion result.
- **Part L, the live demo** (E1531D-11 to E1531D-19). QA runs one scratch project p1 through the CLI and the hub's frame protocol. All three fake harnesses and a Codex item session go through launch, liveness, re-find, restart resume and stop on `local`. The Codex item session's live sandbox roots are read, including one root reached through a symlink. The task branch is read in the territory. An artifact is created from a path inside the item's worktree. Placement is refused for the Coordinator and the Aide. A `t1` row whose pid is a live local process is never signalled.
