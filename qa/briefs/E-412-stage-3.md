# Stage QA brief: E-412 stage 3 — deltas, resume, the network and the door

Everything the run needs is in this file or in the files it names: whoever runs it cannot ask. Commands are for bash (zsh reads `$S:q` as a modifier).

## Stage

- Epic: E-412 (the web edge and the protocol extension, under R-377).
- Exact stage name: deltas, resume, the network and the door.
- Items: T-985, T-986, T-988, T-989 (lane one holds T-985 then T-986; lane two holds T-988 then T-989). Findings fixes added to this stage by `task.plan set` after writing are listed in the request; none at writing.
- Policy: full/after-stage.
- Scope: the product's complete QA scope for E-412, so the four items' changed behaviour plus a short regression pass over stages 1 and 2. T-985: one emit point numbering every model delta (tracker `task` frames included) with no gap after the snapshot; slim `task` frames carrying the changed item and only the changed layers; the verification queue pushed only when its holder or waiters change; a pin or mute sending re-projected rows (a bare `{type: "visibility"}` stays on legacy connections); one serialization per feature set; Neovim frames unchanged. T-986: `hello.resume {epoch, seq}` and the `resume` request; replay of exactly the missed deltas from the in-memory ring (15 minutes, 4 MiB), then live ones; a fresh snapshot in the current epoch when the ring no longer covers the number or the epoch differs; a new epoch after a hub restart; `resync` (`queue-limit` past 4 MiB unsent, `snapshot-required` when no snapshot was negotiated). T-988: `[web] bind` serving only the web edge on its address while the spokes stay on `127.0.0.1`, with the dated ADR 0003 amendment; `[web] origin` adding the tunnel's Host and exact HTTPS Origin and setting `Secure` only when both match, never from forwarded headers; `cland web --qr` (tunnel first, else LAN, refusing loopback alone) with the vendored MIT encoder and no runtime dependency; doctor's `web network` warning for plain HTTP on a network bind. T-989: server pings every 30 seconds and a 60-second silence close; the welcome's `features` and `buildStamp` (with the build digest now covering `shared/protocol-frame.ts` and `shared/wire/`) and a stale page reloading once; a protocol-refused web hello carrying `action: "restart-hub"`; binary frames closed with 4003 and JSON frames capped at 1 MiB (1009 above); every adapter's `terminal: 'none'`. Regression (stages 1 and 2, compact): the edge, the link and the cookie, the upgrade checks, the authority table, the cookie's hash-only storage, the snapshot, history pages and capability URLs (including T-1042's symlinked-ancestor fix), plus their named tests.

cat > "$Q/frames.cjs" <<'JS'
'use strict';
// QA frame client (E-412 stage 3). It prints what the scratch hub sends and asserts nothing.
// node "$Q/frames.cjs" web|unix ['<extra hello fields as JSON>'] < frames.jsonl   (run in the project directory)
// web: Cookie from the file $QA_COOKIE (default $Q/cookieA); URL ws://$QA_ADDR:<webPort>/ws (QA_ADDR default
//   127.0.0.1, '[::1]' for p2); Origin $QA_ORIGIN (default http://$QA_ADDR:<webPort>); Host $QA_HOSTHDR when set.
// unix: socket and secret from ./.cland/hub.json (the secret is never printed).
// stdin: one frame per line (ids q1, q2, ... added when missing), or a pseudo-frame:
//   {"qa":"binary","text":"…"}      the text's UTF-8 bytes as one binary message; waits up to 3 s for the close
//   {"qa":"bytes","n":N,"id":"…"}   a hub.status text frame of exactly N UTF-8 bytes; waits for its result or the close
//   {"qa":"resume-self"}            a resume request at this connection's own last model position
// Extra lines: qa-sent, qa-ping (QA_PINGS=1), qa-closed {code, reason, ms}, qa-end, qa-timeout, qa-error; ms counts
//   from the hello. An extra hello field overrides the default (for example {"protocol":999}).
// QA_STREAM=1: print each frame on arrival (default: all at the end). QA_HOLD_MS=N: keep the socket N ms after the
//   input, or until the hub closes it. QA_SETTLE: ms to wait after the last answer (default 700).
// QA_CURSOR=<file>: write {"epoch","seq"} of the last model position received (snapshot.end or numbered delta).
// QA_AUTOPONG=0: do not answer server pings (web). QA_FULL=1: print snapshot values and whole frames.
const fs = require('node:fs');
const net = require('node:net');
const path = require('node:path');
const { createRequire } = require('node:module');

const mode = process.argv[2];
if (mode !== 'web' && mode !== 'unix') { console.error('usage: frames.cjs web|unix [hello-json] < frames.jsonl'); process.exit(2); }
const extra = process.argv[3] ? JSON.parse(process.argv[3]) : {};
const input = fs.readFileSync(0, 'utf8').split('\n').filter(line => line.trim()).map(line => JSON.parse(line));
const discovery = JSON.parse(fs.readFileSync('.cland/hub.json', 'utf8'));
const env = process.env;
const received = [];
let waiters = [];
let next = 0;
let start = Date.now();
let cursor = null;
let ending = false;
const sleep = ms => new Promise(done => setTimeout(done, ms));

function show(frame) {
  if (env.QA_FULL) return frame;
  if (frame.type === 'snapshot') return { type: frame.type, epoch: frame.epoch, seq: frame.seq, domain: frame.domain, bytes: Buffer.byteLength(JSON.stringify(frame)), keys: Object.keys(frame.value ?? {}) };
  if (frame.type === 'task') return { type: 'task', id: frame.id, epoch: frame.epoch, seq: frame.seq, title: frame.item === null ? null : frame.item?.title, itemsKey: Object.hasOwn(frame, 'items'), layers: frame.layers };
  if (frame.type === 'message') return { type: 'message', epoch: frame.epoch, seq: frame.seq, topic: frame.topic?.id ?? frame.topic, messageSeq: frame.message?.seq, text: frame.message?.text, from: frame.message?.from };
  if (frame.type === 'visibility' && frame.rows) {
    const rows = {};
    for (const [key, list] of Object.entries(frame.rows)) rows[key] = Array.isArray(list) ? list.map(r => ({ id: r.id ?? r.name, seq: r.seq, text: r.text, layer: r.layer })) : list;
    return { type: 'visibility', epoch: frame.epoch, seq: frame.seq, rows };
  }
  if (frame.type === 'result' && frame.value && Array.isArray(frame.value.messages)) {
    const m = frame.value.messages;
    const brief = x => x && { seq: x.seq, text: x.text, from: x.from, fromKind: x.fromKind };
    return { ...frame, value: { topic: frame.value.topic?.id, count: m.length, seqs: m.map(x => x.seq), first: brief(m[0]), last: brief(m.at(-1)) } };
  }
  return frame;
}
function note(frame) {
  received.push(frame);
  if (env.QA_STREAM) process.stdout.write(`${JSON.stringify(show(frame))}\n`);
  for (const w of [...waiters]) if (w.test(frame)) { waiters = waiters.filter(x => x !== w); w.done(frame); }
}
function onFrame(frame) {
  if (typeof frame.epoch === 'string' && typeof frame.seq === 'number' && frame.type !== 'snapshot') cursor = { epoch: frame.epoch, seq: frame.seq };
  note(frame);
}
function waitFor(test, ms = 5000, from = received.length) {
  const seen = received.slice(from).find(test);
  if (seen) return Promise.resolve(seen);
  return new Promise((resolve, reject) => {
    const w = { test, done: frame => { clearTimeout(timer); resolve(frame); } };
    const timer = setTimeout(() => { waiters = waiters.filter(x => x !== w); reject(new Error('timeout')); }, ms);
    waiters.push(w);
  });
}
function connect() {
  return new Promise((resolve, reject) => {
    const closedFrame = (code, reason) => ({ type: 'qa-closed', code, reason, ms: Date.now() - start });
    if (mode === 'web') {
      const { WebSocket } = createRequire(path.join(env.QA_W, 'package.json'))('ws');
      const cookie = fs.readFileSync(env.QA_COOKIE || path.join(__dirname, 'cookieA'), 'utf8').trim();
      const addr = env.QA_ADDR || '127.0.0.1';
      const origin = env.QA_ORIGIN || `http://${addr}:${discovery.webPort}`;
      const headers = { Cookie: cookie, ...(env.QA_HOSTHDR ? { Host: env.QA_HOSTHDR } : {}) };
      const ws = new WebSocket(`ws://${addr}:${discovery.webPort}/ws`, { origin, headers, autoPong: env.QA_AUTOPONG !== '0' });
      ws.on('unexpected-response', (req, res) => { req.destroy(); reject(new Error(`upgrade refused: HTTP ${res.statusCode}`)); });
      ws.on('error', reject);
      ws.on('message', (data, binary) => onFrame(binary ? { type: 'qa-binary', bytes: data.length } : JSON.parse(data.toString())));
      if (env.QA_PINGS) ws.on('ping', () => note({ type: 'qa-ping', ms: Date.now() - start }));
      const closed = new Promise(done => ws.on('close', (code, reason) => { if (!ending) note(closedFrame(code, reason.toString())); done(); }));
      ws.on('open', () => resolve({ send: frame => ws.send(JSON.stringify(frame)), raw: (data, binary) => ws.send(data, { binary }), end: () => ws.terminate(), closed }));
    } else {
      const socket = net.createConnection(discovery.socket);
      let buffer = '';
      socket.setEncoding('utf8');
      socket.on('data', chunk => {
        buffer += chunk;
        for (let nl = buffer.indexOf('\n'); nl >= 0; nl = buffer.indexOf('\n')) {
          const line = buffer.slice(0, nl).trim();
          buffer = buffer.slice(nl + 1);
          if (line) onFrame(JSON.parse(line));
        }
      });
      socket.on('error', reject);
      const closed = new Promise(done => socket.on('close', () => { if (!ending) note(closedFrame('socket', '')); done(); }));
      socket.on('connect', () => resolve({ send: frame => socket.write(`${JSON.stringify(frame)}\n`), raw: data => socket.write(data), end: () => socket.destroy(), closed }));
    }
  });
}
function exchange(link, frame) {
  const from = received.length;
  const hello = frame.type === 'hello';
  if (!hello && frame.id === undefined) frame = { ...frame, id: `q${++next}` };
  const wait = waitFor(hello ? f => ['welcome', 'result', 'error', 'qa-closed'].includes(f.type) : f => (f.type === 'result' && f.id === frame.id) || f.type === 'qa-closed', 5000, from);
  link.send(frame);
  return wait;
}
async function pseudo(link, spec) {
  const from = received.length;
  if (spec.qa === 'binary') {
    note({ type: 'qa-sent', binary: true, bytes: Buffer.byteLength(spec.text ?? '') });
    link.raw(Buffer.from(spec.text ?? '', 'utf8'), true);
    await waitFor(f => f.type === 'qa-closed', 3000, from).catch(() => note({ type: 'qa-timeout', waiting: 'close after a binary frame' }));
  } else if (spec.qa === 'bytes') {
    const id = spec.id ?? `b${++next}`;
    const envelope = JSON.stringify({ type: 'hub.status', id, padding: '' });
    const fill = spec.n - Buffer.byteLength(envelope);
    if (fill < 0) throw new Error(`${spec.n} bytes is below the envelope`);
    const payload = envelope.replace('"padding":""', `"padding":"${'x'.repeat(fill)}"`);
    note({ type: 'qa-sent', id, bytes: Buffer.byteLength(payload) });
    link.raw(payload, false);
    await waitFor(f => (f.type === 'result' && f.id === id) || f.type === 'qa-closed', 5000, from).catch(() => note({ type: 'qa-timeout', waiting: id }));
  } else if (spec.qa === 'resume-self') {
    if (!cursor) throw new Error('no model position to resume from');
    await exchange(link, { type: 'resume', epoch: cursor.epoch, seq: cursor.seq }).catch(() => note({ type: 'qa-timeout', waiting: 'resume' }));
  } else throw new Error(`unknown pseudo-frame ${spec.qa}`);
}
function report() {
  let out = '';
  for (const frame of received) out += `${JSON.stringify(show(frame))}\n`;
  return out;
}
(async () => {
  let link;
  try {
    link = await connect();
    const features = Array.isArray(extra.features) ? extra.features : [];
    const from = received.length;
    start = Date.now();
    const answer = await exchange(link, { type: 'hello', protocol: 2, client: mode === 'web' ? 'web' : 'ui', ...extra, ...(mode === 'unix' ? { secret: discovery.secret } : {}) });
    if (answer.type === 'welcome' && features.includes('snapshot') && !extra.resume) {
      await waitFor(f => ['snapshot.end', 'snapshot.refused', 'qa-closed'].includes(f.type), 5000, from).catch(() => note({ type: 'qa-timeout', waiting: 'snapshot.end' }));
    }
    for (const frame of ['welcome', 'result'].includes(answer.type) ? input : []) {
      if (received.some(f => f.type === 'qa-closed')) break;
      if (frame.qa) await pseudo(link, frame);
      else await exchange(link, frame).catch(() => note({ type: 'qa-timeout', waiting: frame.type }));
    }
    await sleep(Number(env.QA_SETTLE ?? 700));
    if (env.QA_HOLD_MS) await Promise.race([link.closed, sleep(Number(env.QA_HOLD_MS))]);
  } catch (error) {
    note({ type: 'qa-error', message: error.message });
    process.exitCode = 1;
  }
  if (env.QA_CURSOR && cursor) fs.writeFileSync(env.QA_CURSOR, `${JSON.stringify(cursor)}\n`);
  ending = true;
  process.stdout.write(env.QA_STREAM ? `${JSON.stringify({ type: 'qa-end', ms: Date.now() - start })}\n` : report());
  link?.end();
  setTimeout(() => process.exit(), 1000).unref();
})();

## Probes that mislead

- Process probes exclude their own shell: use `pgrep`'s bracket trick or exclude the probe's process tree.
- Never treat `hub status` of the live project as evidence: the scratch hubs are the ones whose `.cland/hub.json` sits under `$Q/p1` and `$Q/p2`. Confirm `pwd` before each command; `frames.cjs`, `wp` and `hs` read `.cland/hub.json` from the current directory.
- Model numbers are shared by every client in an epoch. A coalesced `inbox`, an `event` or a `presence` frame can take a number between the frames a check causes: judge contiguity with the `seqs.cjs` summary and identify the frames a check caused by item id, topic or text, never by position or by "the last" line. Persistence checks name their row by its `seq` or id (stage 2's M5 finding: an inline artifact's chip follows the message, so "last" is the chip).
- Secret and cookie probes enumerate regular files only (`find … -type f`): a recursive `grep -r` reads `hub.sock` and exits 2 (stage 2's M2 finding). `grep -F -f <file>` with an empty line in the pattern file matches every file: the checks print the empty-line count, which must be `0`. Patterns go in files, never on a command line, where `ps` would show them.
- `QA_STREAM=1` captures are printed as frames arrive, so a capture of a backgrounded helper is complete only after `wait`; the `qa-end` line marks the end. Without `QA_STREAM` the helper prints everything at the end.
- With `resume`, the helper sends its input at once instead of waiting for `snapshot.end`; a request result is ordered after the replay (M4), and the fallback checks of M5 rely on `QA_SETTLE=1500` instead.
- The web welcome now always carries `features` (empty without opt-in) and `buildStamp`; stage 2's expectation of no `features` key on a plain web hello is superseded by T-989. Local (Unix) welcomes keep their old shape.
- The ping sweep runs on the hub's own 30-second interval, not from each socket's connection: the first ping comes within 30 s of the hello and the silence close lands between 60 and 90 s. A client terminated by the server sees close code `1006`; `4003`, `4000` and `1009` are sent close codes.
- `curl` needs `-g` for an IPv6 literal URL (`http://[::1]:…`); without it, curl reads the brackets as a glob. A `000` with `curl exit 7` is the evidence that nothing listens on that address; if another process happens to own that port on 127.0.0.1, `lsof` shows it: record that as a confound, not a product fault.
- `curl` removes `../` and `./` segments before sending unless `--path-as-is` is given: a `200` on a traversal URL without it tested a different path.
- A curl WebSocket upgrade that succeeds prints `101` and then waits for frames until its `-m` limit (exit 28): the printed code is the evidence, not the exit status.
- `curl` with `-I` sends HEAD, which `/auth` answers `405` without spending the link: spend a link only with GET.
- `cland doctor` may report other rows as `warn` in a scratch project (harnesses, Neovim); only the `web network` and `web bundle` lines are judged, and its exit status is not.
- `$Q/p3` names `192.0.2.4`, a documentation address that is not configured here: starting its hub would only fail to bind, but the brief never starts it.
- `node:sqlite` may print an `ExperimentalWarning` on stderr (M17); it is not a failure.
- `web --sessions`, `web --revoke`, `web --qr` and `artifact new --path` refuse a session's shell: the commands must run with the `CLAND_SESSION_*` variables unset, as `env.sh` does through the credential filter. A refusal naming "only the human" means the environment leaked, not a product fault.
- The webPort is kept across restarts (stage 1, T-978); a changed `WP` after M6 is a stage 1 regression.
- Targeted test runs obey cover-quiet admission: if the Coordinator holds a cover slot, wait; `--test-concurrency=1` keeps one test file at a time.
