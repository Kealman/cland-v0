# QA brief: T-268 Epic: Suite spend and Linux portability

This brief is the Definition-of-done demo of epic T-268. QA runs it on `dev` in the human's place (decisions D16 and D19 of v0.1 §4: epics wait for no human demo). QA plays the human with the `cland` CLI and a shell. It runs the spawn census on `dev` and compares it with the census made before the first cut. It runs `cland verify all` on `dev`. It checks the process listing and the five formerly failing files in the local Ubuntu container. It runs one full suite on a DigitalOcean c-8 droplet with T-282's driver under decision D25. It reads the docs. Everything the run needs is in this file or in the files it names.
