# QA brief: E-1311 — Definition of done (media, the upload frame and speech)

## Item

E-1311, Definition of done C1–C10. It has three stages, each with QA scope none: "the upload frame, the files client and the speech seam", "media on Telegram, the composer and doctor", and "voice end to end and the docs". The request names the full dev SHA under test and the Linux droplet and macOS stage cover logs that closed the last stage.

The demo runs inside the sealed scratch hubs the tests build (rule 15):
- the fake Bot API in `hub/test/fakes/telegram/`;
- fake speech providers (a loopback ElevenLabs stand-in, and a command stand-in);
- an isolated Chrome Headless Shell for the web cases (rule 18);
- headless Neovim, with `CLAND_OPENER` stubbed for the system viewer.

Only made-up tokens and keys are used. QA never reads, prints or copies ~/.config/cland/sandbox-remote.secrets.toml. It never uses a real Telegram bot, ElevenLabs key or token, and never passes a value in argv. The live run with the human on the real bots is not part of this epic.

## Build

Use a clean detached worktree at the full dev SHA named in the request, with `node_modules` and `hub/node_modules` linked from the project root (`ln -sfn`). HEAD must equal that SHA. Build `web/dist` first (`npm run build --workspace web`, or the repository's web build script) so the web cases find the bundle. Every child (T-1381–T-1395) needs a dev landing receipt (an `Item: T-n` trailer). Before the verdict, check freshness with `cland demo status E-1311 --commit <sha> --json`.

## Probes that mislead

- The live hub runs code from its last restart (#59), and no Telegram remote or speech key is enabled on it. Its behaviour is no evidence. The tests at the build are.
- A `node --test` exit 0 whose name pattern matched nothing is not a pass: confirm the named cases appear in the output. A skipped M3 case is BLOCKED.
- An album of audio files is one message with every file and **no transcript**. This is the human's decision c848fe23 (2026-10-28 19:32Z), not a finding; per-file album transcripts are T-1433.
- A successful voice answer to a card keeps no audio, while failed, empty or unmatched notes keep their audio in General. This is the human's decision 62b8d32f, not a finding.
- C5 has no test with an image of exactly 10 MB, only the 11 MB and 12 MB cases. M5's source check covers the boundary.
- C6's seam shape is checked by the typecheck and M6's source check; no runtime test asserts it.
- Discord media (E-1312 stage 5), the live bots, and the speech provider's real network are out of scope.

## Out of scope

Real Telegram or Discord, any real token, bot or ElevenLabs key, the sandbox secrets file, Discord media (E-1312), setup and workbench rows (E-1313), and rerunning the full suites the covers already ran.
