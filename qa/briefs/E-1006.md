This brief is the Definition-of-done demo of epic E-1006. QA runs it in the human's place, at a full `dev` SHA that the request names. It has three parts.

- **Part D, the droplet.** One demo lease at the requested commit, through `cland demo` only. On it run the children's test files one at a time, a scratch-project write check, and the ten-minute idle diagnostic of T-1084.
- **Part L, local macOS.** The copied-tracker startup probe, which asserts macOS, and two planted over-budget regressions of the unchanged smoke test. All of these run in clean detached worktrees at the same SHA.
- **Part R, records, read-only.** The human's and the stand-in's recorded measurements for C1 and C2, the documented retention rule, a read-only capture count of the live tracker, and the Coordinator's epic-occasion full suite at the same SHA.

## Probes that mislead

- A skip from a Neovim test (no Neovim found) is BLOCKED, never PASS. Check `ℹ skipped`, and check that each named test appears in the output.
- The startup budget and the 2 s decode are hard limits in the tests, not load-scaled. Speed is judged on measured wall times, never projections. E1006-DOD-07's figure comes from the tracker committed at `S`, not from the live root, and it is not the human's measurement.
- C1 and C2 are local evidence: the human's words and cland-impl's samples recorded on the epic. Never start, attach to or sample the human's live Neovim or hub to "confirm" them.
- E1006-DOD-10 measures its own process CPU. A busy lease inflates it through contention, so run nothing else alongside it.
- A planted test failure on any message other than the one named is not proof of that budget. Read the `not ok` block for the first test, not only the exit code.
- In E1006-DOD-23, mtime alone can mislead: retention uses the latest of mtime, ctime and birthtime. That check counts new captures, so it uses `-newermt`, and it never writes or deletes in the live tracker.
- Process probes exclude their own shell: use the bracket form of `pgrep`.
- Re-check test names, file paths and the plant anchor with grep at `S`; renames happen.
