# QA brief: E-1538 — Definition of done (Shape-B readiness)

This brief is the Definition-of-done demo of epic E-1538 (qa skill, "Epic demos on a named dev commit"). QA runs it in the human's place at a named `dev` commit and records one epic verdict that names, by id, the criteria it verified (C1–C5). Everything the run needs is in this file or in the files it names: whoever runs it cannot ask. Commands are for bash (zsh reads `$B:h` or `$S:q` as modifiers, does not split an unquoted `$F`, and prints `type` differently).

**Where it runs.** Every case runs locally, on macOS, from a clean detached worktree at the requested SHA, with `QA_DEMO_EPIC` unset. There is no `cland demo start`, so no lease, deadline, lifetime or cost. Each case names `local macOS` in its `where` column; none names `droplet`, for these reasons: the DoD itself says no cluster and no real droplet is involved; the reused scratch functions use BSD `sed -i ''`; the browser rows use the suite's Chrome Headless Shell from the installed `playwright-core`; `hub/test/doctor-cli.test.ts` needs the pinned Neovim; and the named files must run on the same machine and build as the scratch journeys they back. `cland demo status` reads freshness without a lease (skill: "This same check works without a remote lease after a local fallback"). No real browser, no GUI, no real harness, no real DigitalOcean API, token, droplet, key or snapshot, no real `ssh`: the scratch hubs run the fake `claude`, `codex` and `opencode` of `hub/test/fakes/`, DigitalOcean is the repository's fake API on 127.0.0.1 (`hub/test/fakes/digitalocean/fake-api.ts`, driven by stage 1's `fakedo.mjs` with a sentinel token the fake itself generates), and the transport contract runs on its own fixture (`hub/test/transport-contract-fixture.ts`, the fake sshd and the fake transport pairing).

## Probes that mislead

- **Overlays after the seal** (E-1536 DoD correction a54f9472; E-1532 stage 2). `env PATH=… cland hub start`, `PS_LOG=… PATH=… cland doctor`, `TMPDIR=… node probe.mjs …` or any `NAME=value command` prefix inside a sealed subshell adds variables `fixtureEnvironment` never filtered. - **Neovim is not on the inherited PATH** (correction 76c6412f). Resolve it with `node nvim/bin/nvim-path.ts` at the build (the pinned v0.12.5) and pass its directory to the seals; never use a Homebrew `nvim`. `doctor-cli.test.ts` (E1538D-23) checks the pinned version.
- **Scanner-flagged text** (E-1536 DoD correction 2f3a56df). The stage-1 brief's static patterns and prose trip the publication scanner. Never copy a brief, an extracted block, a brief diff, `env.sh`, `seal1.mjs`, `rowref.mjs` or a probe under `$EV`; record digests, line counts and first-line prefixes only. E1538D-30 runs the shared `assertPublishable` over every capture with a planted positive control.
- **Census probes see themselves.** A census that greps `ps` for a scratch path also matches its own command and any shell whose command line spells that path. Stage 2's `probe census` excludes its own pid; this brief's `cen` excludes itself and every ancestor; never type a scratch root's literal path into the command that runs a census (use the variables). The `alive` lines print the executable name only.
- **The root census** leaves out `.claude/settings.local.json`: a pre-existing harness-local file, not run output.
- **Socket paths.** macOS allows 104 bytes for a Unix socket path, NUL included. `$T` is as long as the suite's root, not longer; the scratch projects sit in short roots. An `EINVAL` on connect with a long path is the socket limit (T-1653), not a network error.
- **Created ids come from listings, never from replies** (rule 22). The fake's droplet and key ids are read from its `/state` listing and saved one per file with a trailing newline (stage 1's `ids` mode); no row here takes an id from a send or create result.
