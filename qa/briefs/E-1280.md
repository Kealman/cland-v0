## Probes that mislead

- The latest dev may be ahead of the covered commit. That is fine when `demo status` reports `current: true`, meaning no later commit touches files changed by E-1280's merges.
- A review verdict at an older head doesn't count: match each child's verdict and verify heads against its landed head.
- A cover log names files by path and cases by full name; a renamed case is not a missing one. Grep the build before calling a case absent.
- A child's test file can be shared with another child; one passing file serves both only if it holds each child's named cases.
