# QA brief: T-271 Remote executors

This brief is the Definition-of-done demo of epic T-271. QA runs it on `dev` in the human's place (decisions D16 and D19 of v0.1 §4: epics wait for no human demo). QA plays the human with the `cland` CLI and a `bash` shell. It has four parts:

- **Root reads and targeted tests.** The children, their merges and the plan, read from the live tracker. The executor test files are run one at a time, with the token removed from their environment.
- **A scratch project, a copy of `dev`, with its own hub started with the token.** This part creates billable droplets, one at a time:
  - `cland executor prepare` makes the snapshot (one c-8 builder);
  - the hub-stop step: a c-8 run, the hub stopped mid-run, the watchdog deleting the droplet at its 15-minute lifetime, and the next start's sweep;
  - one c-16 speed run;
  - a hub started without the token, whose `cland verify` falls back to local with a warn-level event.
- **References.** T-347's C6 is the parallel proof, and A-2217 is the MicroVM experiment.
- **Docs.** The README, the clauses and the skills.

Everything the run needs is in this file or in the files it names.

**The token scanner.** Never pass the token's value as an argument: `grep -F -- "$DIGITALOCEAN_TOKEN"` puts it in the process table for every user of the host to read. Write `$D/scan.mjs`. It reads the value in-process and prints only counts and the paths that hold a hit:

```js
// scan.mjs <path|-> …: literal search for DIGITALOCEAN_TOKEN's bytes. Prints {files, hits, where}; never content.
import { readFileSync, readdirSync, lstatSync } from 'node:fs';
import { join } from 'node:path';
const token = process.env.DIGITALOCEAN_TOKEN;
if (!token || token.length < 16) { console.log('scan impossible: token absent'); process.exit(2); }
const needle = Buffer.from(token);
let files = 0, hits = 0; const where = [];
const scan = (buf, name) => { files++; if (buf.includes(needle)) { hits++; where.push(name); } };
const walk = p => { const s = lstatSync(p, { throwIfNoEntry: false }); if (!s || s.isSymbolicLink()) return;
  if (s.isDirectory()) { for (const e of readdirSync(p)) if (e !== 'node_modules') walk(join(p, e)); } else if (s.isFile()) scan(readFileSync(p), p); };
for (const p of process.argv.slice(2)) p === '-' ? scan(readFileSync(0), 'stdin') : walk(p);
console.log(JSON.stringify({ files, hits, where }));
process.exit(hits ? 1 : 0);
```
