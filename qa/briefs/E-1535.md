Commands are for bash (start `bash` first; zsh reads `$S:q`, `$B:h` or `${B}:hub` as modifiers, does not split unquoted path lists and does not split `set -- $pair`; always brace a variable before `:`). **No real SSH, host, droplet (other than the hub-owned demo lease that `cland demo` provisions), volume, snapshot, DigitalOcean API, key, credential, harness login, browser sign-in, sudo, mount, Telegram, Discord, speech API, npm registry or network beyond the demo delivery (R-1530's QA rule).** Every provider, volume, harness, messenger and sign-in in this run is a fake inside a named test file or the scratch hub: the fake host provider with directory-backed volumes that attach to one machine at a time and a snapshot rate limit, fake SSH and scp, fake agents on Unix sockets, the fake Claude Code, Codex and OpenCode binaries with their rotating login files and dead-login signals, the test messenger, FakeClock, temporary SQLite.   - C2: A disk login keeps its volume, detaches at host stop and re-attaches at the next bind, and a rotated login written on one host is read at its newer generation on the next.
  - C3: Snapshots are taken after a sign-in and at most daily, the last two kept, and a host stop never waits on a snapshot.

  - C7: A login is signed in through the harness's own flow in the terminal or from a card, and nothing cland starts runs a logout.
  - C8: A dead-login signal marks the login signed out, placement skips that host, sessions there keep running, `cland login signin` reuses the same volume, and a second sign-out of one account within a day adds the hint.
  - C9: At start the hub frees a login whose host is gone, and `cland login remove` is refused while a login is in use.
  - C10: The ADR and spec v0.1.2 §3.13 carry the amendment of spec §3.12.

## Probes that mislead

- **Generated names cannot be certified by `qa lint`.** The loop titles (the dead-login classifier, the hint window, the sign-in card, the Codex remote error, the settled-fixture restart, the card option, the fold, the terminal interruption and the native relaunch cases) are expanded in `expect.json` and checked by `tap.mjs` at the run.
- **`cland demo exec` has no stdin** and returns output when the command ends, capped at 8 MiB: each file runs in its own exec and the probes travel as single argument strings.
- **The native files run on this Mac, not on the droplet** (one file per preservation slot); a native failure is judged as it stands; it is not moved to the droplet to pass.
