## Probes that mislead

- Process probes exclude their own shell: use `pgrep`'s bracket trick (`chrome-headles[s]-shell`) or exclude the probe's process tree.
- The browser census is meaningful only while this Mac runs no other Web phase: a local cover, E415-DOD-17 or another session's Web run moves the `before` count; wait and rerun, never record a PASS on a moved baseline.
- `cland web`, `hub start` and `hub stop` refuse a session's shell: the walkthrough's fixture runs them with the `CLAND_*` variables unset, as `env.sh` does. A refusal naming "only the human" means the environment leaked, not a product fault.
- T-1060 (if still open): a hub with the web edge may outlive `hub stop`'s deadline; the walkthrough's fixture asserts its own stop. A census or "scratch hub stopped" failure naming it is FAIL with the exact output.
- The live edge serves the root's `web/dist`: Part B judges `S` only when step 0's `sources` digests are equal. `Offline`, `—` counts and empty object groups in the real browser are expected without a cookie and are not findings; the real browser cannot open the drawer or list palette objects, and that absence is not a finding.
- Key events from computer use carry the physical codes of the human's current layout; never switch the layout. The Cyrillic path is proven by the Headless Shell rows with key value `ж`.
- The mechanical prose rule counts words, not meaning: a seeded title is a fact. If only a title is flagged, record a low finding about the checker's rule, not a product failure.
- `verify --dry-run` from `X` decides its selection against the fetched `origin/dev`; a moved `origin/dev` can add deciding files. Read the line; the Web shard is the criterion.
- A green task run can come from the tree-hash cache; `--fresh` prevents that. A log without `$ node hub/test/run-suite.ts --tier Web` did not run the Web phase, whatever the result says.
- Droplet prepare logs are in the run's `delivery.log`, not the suite log. Duration and budget lines are report-only.
- "No skip": the Web files need Chrome Headless Shell; a skipped file or `Web unavailable` is BLOCKED on a host that should have it (the droplet snapshot and this Mac do), never PASS.
- Re-check helper, selector, file and test names with grep at `S`; renames happen.
