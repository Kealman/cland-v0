# QA brief: T-269 Prefixes and categories

This brief is the Definition-of-done demo of epic T-269. QA runs it on `dev` in the human's place (decisions D16 and D19 of v0.1 §4: epics wait for no human demo). It has two parts.

- **Part A, a scratch project with its own hub.** It holds the item files of `dev` from before the live migration (commit 5d74dbb). QA runs `cland task migrate --dry-run`, then `cland task migrate` with the hub stopped, and compares them. Then QA restarts the scratch hub and checks the prefixes, the category kind, the narrowed unscheduled, `idle_from`, the clauses, the count line and `gi`, through the CLI, one driver spoke, one UI client and one headless workbench.
- **Part B, the live tracker, read-only.** It starts only after the Coordinator confirms the live migration in Agents. A headless workbench attaches to the live hub as a UI client and reads the release row, the count line and `gi` on an old `T-` id in a live thread. Part B writes nothing to the live tracker, the live hub or the live `ui.json`.

The children's hub and Neovim tests corroborate, **one file at a time**. No harness session is launched anywhere. Everything the run needs is in this file or in the files it names.

**The frontmatter checker.** `git diff` cannot tell a frontmatter change from a body change. Write `$D/fmcheck.mjs`. It pairs each item file now in `$P` with the file of the same number at a base commit, compares the parsed frontmatter key by key, and compares the bytes after the frontmatter (body and comments):

```js
import { execFileSync } from 'node:child_process';
import { readdirSync, readFileSync } from 'node:fs';
import { createRequire } from 'node:module';
const { parse } = createRequire('/Users/evgeniyivanov/Projects/cland/v0/package.json')('yaml');
const [P, base] = process.argv.slice(2);
const git = (...a) => execFileSync('git', ['-C', P, ...a], { encoding: 'utf8', maxBuffer: 1e9 });
const split = t => { const m = /^---\n([\s\S]*?)\n---\n/.exec(t); if (!m) throw new Error('no frontmatter'); return { fm: parse(m[1]) ?? {}, rest: t.slice(m[0].length) }; };
const num = f => Number(/(?:^|\/)[A-Z]-(\d+)-[^/]*\.md$/.exec(f)?.[1]);
const old = new Map(git('ls-tree', '--name-only', base, '.cland/tasks/').trim().split('\n').filter(f => num(f)).map(f => [num(f), f]));
const changed = {}, created = [], bodies = [];
let renamed = 0, inPlace = 0, same = 0;
const now = readdirSync(`${P}/.cland/tasks`).filter(f => num(f));
for (const f of now) {
  const o = old.get(num(f));
  if (!o) { created.push(f); continue; }
  const a = split(git('show', `${base}:${o}`)), b = split(readFileSync(`${P}/.cland/tasks/${f}`, 'utf8'));
  if (a.rest !== b.rest) bodies.push(f);
  let any = false;
  for (const k of new Set([...Object.keys(a.fm), ...Object.keys(b.fm)])) if (JSON.stringify(a.fm[k]) !== JSON.stringify(b.fm[k])) { changed[k] = (changed[k] ?? 0) + 1; any = true; }
  if (o.split('/').pop() !== f) renamed++; else if (any) inPlace++; else same++;
}
console.log(JSON.stringify({ files: now.length, renamed, inPlace, same, created: created.sort(), bodyChanged: bodies, changedKeys: changed }));
```
