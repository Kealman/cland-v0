# QA brief: T-276 The explorer and the card

This brief is the Definition-of-done demo of epic E-276. QA runs it on `dev` in the human's place (decisions D16 and D19 of v0.1 §4: epics wait for no human demo). It has three parts.

- **The root checks.** The children's Neovim and hub test files, **one file at a time**, the 300-item bench on an idle machine, and six catalogue cases.
- **Part A, a scratch project with its own hub, running `dev`'s code.** The scratch tracker is a copy of the live tracker as committed at the start tip. One coordinator driver spoke receives the explorer's messages. One headless workbench at 200x50 plays the human: the startup view, the tree and its keys, the roots, the card, the narrow layout, the items panel, the messages, `gi` and `gI`, the done colour, live updates, the bench and the preferences across a restart. No harness session is launched.
- **Part B, the live tracker, read-only.** Root reads, then a guarded headless workbench on a mirror root attached to the live hub: the explorer at R-228 and the card of a merged task with its verify result. Part B writes nothing to the live tracker, the live hub or the live `ui.json`.

Everything the run needs is in this file or in the files it names.

It prints what the explorer must draw, from `cland task list --json` on stdin, by the rules of `nvim/lua/cland/explorer.lua` (the root release is the open release with the lowest version; live siblings by rank then numeric id; done siblings after them in closing order, those without `closed` first by `updated`; a container is a release, category, epic or map, or any item with children). ```js

  const v = JSON.parse(s).items, by = new Map(v.map(i => [i.id, i])), num = id => Number(String(id).split('-')[1]);

      direct_panel: panel(K(root.id).filter(i => i.kind === 'task')) };

  }

const by = mark.replace(/^  - done: /, '').split(' · ')[0];
let j = c2 + 1; while (j < lines.length && /^  - /.test(lines[j])) j++;
lines[c2] = lines[c2].replace('- [ ] C2.', '- [x] C2.');
lines.splice(j, 0, `  - done: ${by} · ${new Date().toISOString()}`);
const after = lines.join('\n'), upd = t => (t.match(/^updated: .*$/m) || ['none'])[0];
writeFileSync(file, after);
