## Probes that mislead

- The live hub runs code from its last restart (#57), before E-1309 landed, with no Telegram remote enabled. Its behaviour is no evidence. The tests at the build are.
- A `node --test` exit 0 whose name pattern matched nothing is not a pass: confirm the named cases appear in the output.
- A hub restart is no outage test: after a plain restart the gap is almost always 0. The catch-up cases make outages while the hub runs.
- T-1351 (a failed hub start at openDatabase leaks a FileHandle) is a known separate bug; its DEP0137 warning is not an E-1309 finding.
