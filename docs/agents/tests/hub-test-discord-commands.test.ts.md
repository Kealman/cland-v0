# hub/test/discord-commands.test.ts

T2 on Node 24. Run this file alone with
`node --test hub/test/discord-commands.test.ts`. The production messenger and hub
frame port use loopback fake Discord REST/ws and an injected clock; no real
platform, token, browser or native harness. projectHub seals the fixture's
HOME/XDG/Git environment. The exchange owner registers shutdown before hub
acquisition and joins any late hub before allowing Store close/root removal.

The ten generated cases prove:

- `Discord status is ephemeral with phone groups, session bullets and gateway numbers last`:
  actual private callback, neutral groups through This channel, escaped session
  label, rolling-24h reservation filtering and an independent platform remaining
  value of 137. READY plus an observed native ACK establishes connection.
- `Discord help is ephemeral with short headed sections, command bullets and trust last`:
  actual private help, eight advertised subcommands and trust footer.
- `Discord mute counts General sources once, unmute reports them and replay cannot remute`:
  durable mute receipt, two source suppressions, exact unmute count, replay after
  unmute, unchanged Telegram mute and a post-unmute native sent mapping.
- `Discord decision and question store one General message with kind, provenance and interaction ingress`:
  native Sent callbacks after hub results, captured ingress id and stored General
  history including kind, human identity, Discord provenance and Coordinator delivery.
- `Discord slow command defers privately at two seconds and completes by editing original`:
  hold the hub.status frame; native callbacks remain empty at 1999 ms, type 5/flag
  64 arrives at 2000 ms, then release after three seconds and observe exactly one
  original edit and one acknowledgement. Callback/native edit suppress mentions.
- `Discord stop drains a held command before deferral` and
  `Discord stop drains a held command after deferral`: observe the held frame or
  accepted defer before stop, join shutdown, retain zero timer and no late edit
  assertions after advancing the clock.

The long-status cases `Discord long status preserves literal facts in bounded
private replies immediately` and `Discord long status preserves literal facts in
bounded private replies after defer` send a long project title with Unicode and
Markdown metacharacters through the production port. Observe the native final
footer before asserting every page is within 2000 code points, the original
literal title survives, groups remain ordered, all followups are private, and
only one initial acknowledgement exists. `Discord fake enforces the inclusive
2000-code-point private content budget` accepts exactly 2000 and rejects 2001
for callbacks, original edits and followups.

Native callbacks, original edits and private followups bypass message pacing and
outbox lanes. Their work is joined before shutdown closes storage.
The fake control's text field becomes a real nested slash-command string option;
it never embeds interaction tokens in control receipts. Keep the pairing guide's
foreign user/channel refusals and prior optional-client regressions unchanged.
No wire shape or role clause permission was added.
