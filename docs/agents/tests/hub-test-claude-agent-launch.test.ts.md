T1 scripts command results and native identity/UID facts against private scratch receipts. Empty, duplicate and malformed discovery retain explicit incomplete launch ownership; successful receipts bind generation, job, native conversation, PID, birth and UID. PID reuse refuses receipt consumption. No native harness, timer or socket runs.

A planted jobs symlink is refused before any command and before copying the
planted token outside the private root. A replacement-directory control proves
the post-launch check uses the preflight identity. Concurrent release bounds its
setup observer separately, drains both producers in finally and retains the
final single-producer assertion.

Incomplete launch records preserve config/jobs/private-directory metadata, a
valid printed job and native-stop result for diagnosis; they never authorize a
PID signal. The leading-option job control rejects --all before any native stop.

Restore classification controls adopt only a live validated generation, report
a pending launch, skip released/confirmed-closed records without native identity
reads, and retain a vanished generation while still restoring its healthy peer.
No native process runs in these controls; native downtime/descendant boundaries
are exercised by host-agent-restart.test.ts.

The account-root refusal asserts a generation-bound `refused-before-spawn`
receipt with zero command calls. Ambiguous native discovery has no such receipt.
The already-admitted generation control retains the prior worker's fence instead
of reclassifying its duplicate launch as non-admission.

`native incomplete classification honors owner proof` checks native and
prevalidation generation receipts whose error text contains `cleanup incomplete`,
including bounded oversized results. Typed proof wins over incidental path text;
untyped and real incomplete results retain their fallback classification.
