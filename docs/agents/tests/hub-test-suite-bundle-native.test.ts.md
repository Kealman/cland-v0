# hub/test/suite-bundle-native.test.ts

T3 proves actual admitted commit bytes with disposable native Git. Each periodic
and soak callback uses `suiteCase` in native mode: register the whole-caller
normal/signal owner before acquisition, adopt the fixture root inside setup,
fence every asynchronous step, and join Git close and scheduler delivery before
fixture removal. `fixtureEnvironment` seals HOME, XDG, Git and credentials after
overlays. No real provider, droplet or browser is used.

Advance root source HEAD at delivery, dirty the later source, and bundle using
the scheduler's actual committed-only argument. Fetch into a scratch bare repo;
assert the original source bytes, run head and executor start/completion. Earlier
T2 receipts from suite-soak-component do not prove these migrated T3 identities.

The periodic fixture configures two shards with two classified inputs. Read the
admitted producer plan (`job.shards`, or the whole job for soak), keep a separate
bundle for every producer id, and share one in-flight root-advance operation.
Assert each bundle's captured commit and exact producer ref, receiver source,
temporary-ref deletion and producer start; finish every producer and observe the
parent's durable result. The soak control retains its single-producer contract.
Never substitute the parent id for a sharded producer's Git ref or worker id.
