T2 synthetic native/watch/producer receipts verify failure-only diagnostics,
without launching a native process. Before/after hello boot ids, expected and
observed heads, pending cause, native birth/authority/exit fields and explicit
missing receipts survive projection. Only declared output fields leave the root;
account/environment/launch-plan data are not read or copied. The positive control
plants a bearer and exact secret and verifies redaction. The watch file remains
byte-identical after observation. Reads are capped at64KiB (boot values256bytes),
strings512characters, target/producer counts bounded; an oversized ledger and
unknown observed head remain explicitly incomplete/unknown, never zero or pass.

The current authenticated agent PID is included in the same eight-identity bound.
Captured native boot and recovered-observer boot are explicit fields, derived by
the shared canonical birth parser. The observer value uses that agent's live
identity reply, independently of cached hello; unobservable replies stay unknown.
