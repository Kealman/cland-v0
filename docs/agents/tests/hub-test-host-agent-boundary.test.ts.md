# hub/test/host-agent-boundary.test.ts

T1 `hub/test/host-agent-boundary.test.ts` parses imports, exports and dynamic imports under `hub/src/host/agent/`. Planted package, parent-module and computed imports prove rejection; production modules may import only `node:` built-ins or sibling agent modules. The CLI supplies the product version from the existing shared version owner.

The shared byte decoder also has coalesced, fragmented, multibyte and over-limit controls at the inclusive 1 MiB line boundary. Both stream directions import this decoder.
