# hub/test/remote-workbench.test.ts

T2 uses sealed disposable roots, Unix frames, production Telegram, the loopback
fake Bot API and FakeClock. No real platform, token, GUI or browser is used.
Run the file alone. Fixture readiness/cleanup use telegram-liveness-fixture's
independent native bounds and join stop/connection receipts before removing roots.

The previous-shape protocol-2 hello receives the allowlisted replacement and
continues hub.status/topic.list; a featured hello receives the identical rows in
sessions.remotes, before snapshot.end. Retain the literal field allowlist and
credential/identity negative assertions. C1 changes use native /start, local
pairing.approve, native /mute and /unmute, public General sends, remote.unpair
and config.set. Depth assertions wait for durable remote.status queue facts,
then prove no push at 999 ms and one coalesced push at 1000 ms. Pairing/mute/config
changes bypass that depth window.

Arm outage/stopped frame and native poll-close observers before releasing a held
poll. First failure is offline without advancing behavior time; successful retry
clears offlineSince/lastError. Capture the frame-list boundary before recovery so
an earlier connected frame cannot satisfy it. Native 401/403 retain the shared
cause/stopCause and hub service without tokens. No three-minute General notice
is needed for the frame. These are targeted component receipts, not suite evidence.
