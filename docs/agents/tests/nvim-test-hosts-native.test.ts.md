# nvim/test/hosts-native.test.ts

T3 provisions through the fake host provider on projectHub using host-create-fixture.
It runs the real isolated headless Neovim, native fake SSH, agent and watchdog;
no real provider or credentials. Take the preservation slot and run this file
alone. Capture before/after /private/tmp hc-, ct- and cland-h- name sets.

After the ready receipt and rendered pool row, arm a one-second rendered outage
observer, fence the fake machine with its gone file, and ask its authenticated
master to kill itself using the current owner and token receipt. Require the
named host with ClandRed. Remove the gone file to recover, require the healthy
row and ClandDim. Recovery has a separate bounded setup-style wait; this is not
a recovery latency benchmark. Child scope closes Neovim before the fixture
joins hub, SSH, agent, watchdogs and pending writers, then removes its roots.
