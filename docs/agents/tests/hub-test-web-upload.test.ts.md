# hub/test/web-upload.test.ts

T2 uses sealed projectHub, synthetic multipart bytes, loopback HTTP and human
frame history readback. Redeem a fresh web link in scratch memory; never export
its link or cookie. Admission precedes body consumption. Missing cookie, foreign
Origin, disallowed Host, declared/streamed aggregate overflow and per-file overflow
publish no artifact or message. Assert 405 for GET. The positive omitted-artifacts
request preserves the previous upload frame, exact binary bytes and one message
with two artifacts. Bound request completion independently and pace writes so an
early HTTP refusal can arrive before the client's write error. No native process,
provider, real credential or browser is used.

Held native file writers exercise revocation and edge shutdown. Arm the writer
observer before POST, observe durable session deletion (or edge cancellation),
release the writer, and require joined native close and empty files/index/history.
The stop case restarts the sealed hub to read persisted state. Allocator/writer
controls use a 16 KiB fake payload and assert backing identity as a boolean to
avoid dumping slab contents. HTTP writes share the one private bounded wire
allocation; no stress load or real credential is involved.

`web-upload-owner.ts` registers before POST. Its AbortSignal owns the HTTP request
and body read; tracked revoke/stop operations remain owned on exceptional exits.
Disposal aborts HTTP, releases held I/O and joins requests, controls, native writer
shutdown and rollback through hub stop under one fresh drainage deadline. A missed
receipt reports explicit incomplete drainage. Omitted/aborted setup controls keep
a native handle held, cancel setup with a fake deadline or signal, and require
closed HTTP, native handle close, zero pending owners/timers and empty persisted
artifacts/history after restart. Setup and drainage have separate bounds.
