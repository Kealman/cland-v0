# hub/test/item-summary-lua.test.ts

The default T3 differential copies the fixed 24-item corpus described in
[the corpus guide](hub-test-pinned-tracker.test.ts.md) into a disposable project.
It adds the closed-release/open-epic/planned-task regression, restores closed
containers and tasks through bounded parent pages, compares every retained body
and roll-up against real headless Neovim Lua, and keeps the snapshot byte caps.
Plans, by-id closed text and identity deduplication retain the same assertions.
The full live-body differential is retained at T4 in
[item-summary-lua-soak](hub-test-item-summary-lua-soak.test.ts.md).
