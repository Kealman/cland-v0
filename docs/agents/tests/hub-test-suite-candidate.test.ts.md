# hub/test/suite-candidate.test.ts

The local candidate barrier uses `fakes/finish-poller.ts` with a five-minute base,
scaled by the shared policy when the producer arms its exit-124 backstop.
Teardown stops owned writers and checks an empty native cwd
census before directory removal. The independent short-bound exit regression
lives in executor-safety.test.ts; this file uses a local suite, not a droplet.

The generated producer controls execute real sealed CJS and ESM children; the
ESM host contains top-level await, as the candidate barrier does. A dynamic
import loads the shared policy in either host when the timer is admitted.
Injected loads ten and twenty on ten CPUs produce 600000 and 900000 ms timer
receipts; an explicit 123 ms fault bound stays exact. These measure timer
admission, not elapsed time. Each case owns setup before root acquisition and
joins the original callback, native close and pipe drainage before removal.
Import setup failure exits 125 with a bounded error code; timer expiry exits
124. A generated command retained at module import still samples at runtime.
