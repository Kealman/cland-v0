# hub/test/host-relaunch-native.test.ts

T3 production CodexAdapter with the shipped fake executable, real app-server/spoke
and two fake SSH carriers in one project/transport registry. No provider auth or
real Codex binary claim. The test observes durable first-input consumption files
and native PID/birth, a new harness conversation with stable cland identity/claim,
resolved artifact brief plus loss note, pushed tip and retained source generation.
It captures scoped forward ids/endpoints before movement, then proves a different
destination id and that the old local endpoint stays removed after source carrier
restoration. Source push refusal and destination push success prove lease transfer.

Both hosts use agentBootId with their explicit fake boot file. Environments use
fixtureEnvironment after final overlays; synthetic profile state is scratch-owned.
Captured native fixture owners and publisher flush join before daemon/agent/carrier
teardown and root deletion. Setup uses testWaitMs/eventually; no browser or GUI.

Run serially under the preservation lock. Required loaded proof repeats this
case and the other new native cases five times on macOS (load >=12, actual ranges
recorded) and Linux docker --init with four burners/four CPUs. Allowances name
actual final samples; missing/unexecuted evidence is not a pass.
