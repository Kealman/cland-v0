# hub/test/suite-timing-persistence.test.ts

Guarded semantic local/droplet executor completions feed real Suites and an
isolated SQLite store. Observe the durable completion report before querying
exact-head/tree detail, then close and reopen Store/Suites and repeat. Status
and retained summaries expose counts without generated test titles. The uploaded
droplet status program runs in a VM with in-memory I/O, including the old shape
and damaged sidecar controls; no provider, network or native launch is allowed.
