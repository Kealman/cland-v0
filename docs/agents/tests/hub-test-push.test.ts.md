T3 exercises native local territory publication and CLI identity/refusal flows.
The two lost-publication cases inject at the public original-argv Git boundary:
the actual push must complete before the reply is lost, and an independent
territory confirmation must positively hit its injected failure. The original
CLI exit2, pinned ref, unknown-outcome event, retry guidance and cleanup-error
assertions stay intact. A repaired retry still succeeds.

These callbacks use whole-body/root/native-database ownership and named setup
and action bounds, including the persisted event read and each lock repair.
A planted fixture lock directory has its own failure-path
repair; the native hub closes before original-work admission is sealed, and
all child/resource owners precede root and seam release. Faults inspect the
unmodified public argv rather than a shell's raw first positional argument.
Shared primary-preserving cleanup retains a selected action error if repair or
hub disposal rejects. Nested cleanup attempts disposal even when repair fails,
and adds both secondary diagnostics without replacing the original outcome.
