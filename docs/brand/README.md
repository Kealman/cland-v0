# cland brand, first round

Three directions for the logo, drawn from the workbench's visual vocabulary (`docs/design/main-screen/README.md`): dark ground `#0b0e14`, text `#d6dbe4`, amber `#f0b429` for what needs the human, teal `#35c4a0` for work in progress, green `#7ddc8a` for done.

- **A · Ring**: a lowercase c drawn as an open ring, an amber dot in its mouth. The wordmark carries the same dot in its c.
- **B · Hub**: the hub in teal, five spokes to the sessions, one node amber.
- **C · States**: the four item glyphs, backlog, in progress, review and done, as a 2×2 grid.

The wordmark is drawn from strokes (12 units on an 84-unit cap height, round caps), so it needs no font.

`src/` holds the SVG sources: `mark-*` (512, transparent), `avatar-*` (400, dark ground), `lockup-*-dark|light`. `png/` holds renders made with `rsvg-convert`.
