# The Host owns remote Codex policy paths

Remote Codex policy requires the Host's explicit run directory and resolves writable roots, Git directories and socket directories through that Host's realpath; a missing remote runDirectory refuses before path resolution, and absolute configured writable roots refuse as hub-machine paths even if the same path exists remotely. HostLaunchLayout has no temp-directory field, so Codex uses `/tmp` as the host temp root and canonicalizes it on the Host, including a host-side symlink, while only the local Host uses the hub's `tmpdir()` and discovery-relative run fallback. These are runtime socket permissions, with app-server run sockets denied and connect paths bounded to 104 bytes including the terminator; the exceptions do not grant retained state outside the project.
