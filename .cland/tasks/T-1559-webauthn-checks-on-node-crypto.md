## Summary

A hub module verifies WebAuthn registration (attestation `none`) and assertion by hand on `node:crypto`, with no dependency: it parses CBOR, authenticator data and COSE keys, and checks challenge, origin, RP ID hash, flags, signature and sign counter. It is a deliberate deep module, landed alone because its correctness is the security boundary that L11 builds on (the epic's constraint: an unsafe check leads to an ask about a dependency, never a weaker check).

Hot files: new `hub/src/hub/webauthn.ts` (with a minimal CBOR reader) and its test file. No shared file.
